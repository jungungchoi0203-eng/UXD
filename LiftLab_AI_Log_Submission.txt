1. AI TOOLING DISCLOSURE

I used ChatGPT to help plan, build, and revise my LiftLab website. I described the features and design I wanted, and ChatGPT generated and updated the HTML, CSS, and JavaScript. I provided feedback and requested changes over multiple versions of the app. The assistance included navigation, workout-program templates, personal-record editing, workout logging, progress charts, IPF comparisons, drag-and-drop dashboard customization, and debugging.

The design was influenced by the general layouts of STNDRD, Liftoff, Arrow, and other workout-tracking apps. The site itself is a standalone browser application, not an official version of those apps or of the lifters' published training plans.

4. HOW THE CODE WORKS (ARCHITECTURE AND DATA FLOW)

The application uses HTML for the page structure, CSS for the red and charcoal design, and JavaScript for the interactive features. The main parts of the website are Home, Powerlifting, and Bodybuilding. Program cards contain training templates with exercises, sets, repetitions, and a training schedule. When a user edits a personal record, JavaScript reads the input, validates the weight, updates the athlete data, and refreshes the displayed PRs and the totals. Program previews use the recorded PRs to generate suggested working weights where applicable. Workout logs store completed sets and are used to calculate training statistics and display progress/history on Home. The app remembers athlete data, active programs, and workout history. The layout order is stored separately under the key "liftlab-home-order-v1". Storage may be unavailable in restricted browser previews, so users should test persistence after refreshing and can use the app's backup export/import tools where available. The IPF comparison feature uses age, bodyweight, competition category, and the user's saved squat/bench/deadlift results. IPF GL points are calculated locally. An empirical percentile requires the user to import OpenIPF competition results; without those results the app should not show a made-up percentile. The Home dashboard supports dragging section handles to change the order of Personal Records, IPF Comparison, Current Program, and Progress & History. It also provides move-up and move-down controls.
